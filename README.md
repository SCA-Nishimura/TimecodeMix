# TimecodeMix ⚡

[![Bun](https://img.shields.io/badge/Runtime-Bun.js-black?style=flat-square&logo=bun&logoColor=f9f1e7)](https://bun.sh/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript-blue?style=flat-square&logo=typescript)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Bundler-Vite-646CFF?style=flat-square&logo=vite)](https://vitejs.dev/)

音源ファイル（WAV/MP3）の **Lチャンネルにタイムコード（LTC）** を、**Rチャンネルに元の音源（モノラルミックス）** を完全にパンを振った状態で結合する、ブラウザ完結型の高精度オーディオミキシングツールです。

映像や音響システムの同期、マルチカメラの同期、照明・舞台演出機器（LTC対応機器）とのタイムコード同期音源の制作に最適です。

---

## ✨ 主な機能

- **📁 ドラッグ＆ドロップ対応**: WAVおよびMP3ファイルをブラウザにドロップするだけで即座に解析。
- **🔍 フォーマット自動検出**: アップロードされたWAVファイルからサンプリングレートおよびビット深度をバイナリ解析。
- **⏱️ タイムコード自在調整**: 開始タイムコード（SMPTE形式 `HH:MM:SS:FF`）を任意に指定可能（初期値: `01:00:00:00`）。
- **⏳ 無音遅延（デレイ）追加**: 音声の開始前に任意の無音時間（秒）を挿入可能。タイムコードは無音中も連続してカウントされます。
- **🎛️ 出力ビット深度の指定**: オリジナル音源のビット深度を自動継承、もしくは `16-bit` / `24-bit` PCM WAV を選択して書き出し。
- **🎧 安全プレビュー再生**: LTC特有の耳障りな「ピー」という高周波音から耳を守るため、プレビュー時に **Lch（LTC）のみをワンクリックでミュート可能**。
- **⚡ 高速オフライン処理**: Web Audio API を活用し、サーバー不要・すべてクライアント側で瞬時にエンコードが完了。

## 🛠️ 技術仕様

- **フレームレート**: 選択式（23.976FPS, 24FPS, 25FPS, 29.97FPS(NDF), 29.97FPS(DF), 30FPS(NDF), 30FPS(DF)）
- **LTC音量レベル**: 選択式（-18 dBFS 〜 0 dBFS、整数値、デフォルト: -6 dBFS）
- **変調方式**: Bi-phase Mark Code (BMC) 変調（SMPTE 12M規格準拠）
- **出力フォーマット**: Linear PCM WAV (Stereo: L=LTC, R=Source)
- **ステレオ音源のモノラルミックスダウン処理** ([main.ts:L224-230](file:///home/media/projects/timecode_mix/src/main.ts#L224-L230)):
  - 入力された音源がステレオ（2チャンネル以上）の場合、Rチャンネルに格納されるモノラル音源は左右のサンプルの算術平均 `(L + R) / 2` で計算されます（各チャンネルを -6 dB して加算する処理に相当）。
  - **位相特性による音量レベルへの影響**:
    - **同相成分（センター定位の音）**: 音量レベルに変化はありません（0 dB）。
    - **無相関成分（左右で異なるステレオ音）**: ミックスダウン後に音量レベルが約 -3 dB 低下します。
    - **逆相成分（左右反転した音）**: 左右の波形が互いに打ち消し合い（フェイズ・キャンセレーション）、音量が著しく低下または無音化します。

## 🚀 クイックスタート

### 前提条件
ローカル環境で起動するには、超高速JavaScriptランタイム [Bun.js](https://bun.sh/) が必要です。

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで以下を実行します：
```bash
bun install
```

### 2. 開発サーバーの起動
ローカル開発用サーバーを立ち上げます：
```bash
bun run dev
```
起動後、ブラウザで [http://localhost:3000/](http://localhost:3000/) にアクセスしてください。

### 3. プロダクション用ビルド
静的ファイルとして最適化ビルドを行い、`dist` フォルダに出力します：
```bash
bun run build
```

## 📖 使い方ガイド

1. **ファイルの読み込み**:
   トップ画面の破線エリアに対象のオーディオファイル（`.wav` または `.mp3`）をドラッグ＆ドロップします。自動的にファイル情報の検出（サンプリングレート、ビット深度など）が行われます。
   
2. **パラメーターの設定**:
   - **Start Timecode**: LTC信号の開始タイムコードを入力します（例: `00:59:50:00`）。
   - **Silence Delay**: 音声の開始を遅らせたい時間を秒単位で入力します（例: `10.0` 秒）。この場合、最初の10秒間は無音となり、音源が始まる瞬間のタイムコードがちょうど `01:00:00:00` になるように逆算されます。
   - **Output Bit Depth**: 出力するWAVファイルのビット深度を選択します。
   
3. **処理と書き出し**:
   - 「**Mix & Generate WAV**」ボタンをクリックします。処理は数秒で完了します。
   
4. **プレビューとダウンロード**:
   - 生成されたオーディオは内蔵プレイヤーでプレビューできます。「*Mute LTC (Lch) for safety listening*」にチェックを入れると、不快な同期信号音をカットして音楽側（Rch）だけを安全に試聴できます。
   - 問題なければ「**Download Mixed WAV**」ボタンを押して、タイムコードが結合されたWAVファイルをダウンロードします。
